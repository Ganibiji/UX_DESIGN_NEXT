Ledger · Design system · v1.0

Software for people who close the books.

Ledger is the interface kit behind our finance, operations and people tools. It's built for screens people stare at for eight hours: dense where it helps, calm everywhere else.

Browse components Read the foundations
i.

The number is the hero.

Figures are tabular, right-aligned and never truncated. Chrome steps back so the data can be read at a glance and checked line by line.

ii.

One loud thing per screen.

One indigo button per screen, and indigo marks what's selected or in focus. Everything else stays white or pastel. If everything is emphasised, nothing is.

iii.

Say what happened.

Every error names the problem and the fix. Every destructive action can be undone, or asks first in plain words.

iv.

Works without a mouse.

Each component ships with its keyboard model and is checked with a screen reader before it gets a page here.

Using it

No build step, no framework.

Link three files and write HTML. Components are styled by class and driven by ARIA attributes, so the markup you'd write for accessibility is the markup that styles the component.

<!-- in <head> -->
<link rel="stylesheet" href="assets/tokens.css">
<link rel="stylesheet" href="assets/ledger.css">

<!-- anywhere -->
<button class="btn btn--primary">Post journal</button>
