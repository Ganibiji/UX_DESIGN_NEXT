Write like a good colleague

Our users are accountants and operations staff. They're busy, precise, and they'll notice a wrong word. Write the way a helpful senior colleague talks across the desk: plain, specific, and calm.

Voice

We areSo weWe're not

Error messages

Say what happened, why if it helps, and what to do next. Don't blame the user, don't apologise at length, and never show an error code on its own.

Barclays rejected the payment file
Line 14 has a sort code with 5 digits. Fix it on the supplier, then resend. No money has moved.
What, where, nextThe user knows what to fix and knows their money is safe.
Error 422
An unexpected error occurred. Please try again later.
Code and a shrugTrying again won't help, and the user is left wondering whether money moved.
