Switch

A switch takes effect immediately, like a light switch. If the change waits for a Save button, use a checkbox.

  • Auto-match bank lines
    Match by amount and reference, then ask you to confirm.
  • Lock posted periods
    Nobody can edit entries after a period closes.
  • Multi-currency
    Needs an admin to turn on.

Segmented control & filter chips

Segmented controls switch between views of the same data. Chips narrow a list; several can be on at once, and each shows how many results it holds.
