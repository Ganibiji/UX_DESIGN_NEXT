# Fluent UX Component Lab

A standalone lab that uses only the Fluent-inspired implementation. Open index.html; every page is a standalone HTML file that loads assets/.

- assets/tokens.css: Fluent tokens (--f-*) and semantic aliases, light / dark / high contrast
- assets/components.css: component rules for Fluent only, plus size, density and colour wrappers
- foundations/, design-languages/fluent.html, components/ (37), patterns/ (10), enterprise/ (7), responsive.html, content-guidelines.html

Favorites and preferences are stored in this browser only.
