Text inputs

Labels sit above, hints sit below, and errors replace hints. The field itself stays quiet until someone touches it.

Status StableClasses .field .input .affix

Anatomy

Printed on the supplier's invoice, top right.
  1. Label. Always visible, always above. Placeholder text is not a label — it vanishes the moment someone starts typing.
  2. Optional marker. Mark the exceptions. If most fields are optional, mark the required ones instead.
  3. Field. 34px tall, border at 3:1 contrast against the page.
  4. Hint. Tells people where to find the answer, not what the field is.

AttributeWhy
<label for>Every field needs one. Clicking the label focuses the field, which matters on touch.
aria-describedbyPoints at the hint and any error, so they're read after the label.
aria-invalid="true"Drives the red border. Set it on blur, remove it as soon as the value passes.
autocompleteLets browsers and password managers fill fields. Use the real tokens: email, postal-code, organization.
