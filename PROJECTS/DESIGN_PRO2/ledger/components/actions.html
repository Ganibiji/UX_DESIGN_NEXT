Buttons & links

A button does something. A link goes somewhere. Get that right and most of the rest of this page follows.

Status StableClasses .btn .linkSince 0.2

Hierarchy

Five weights. Most screens need a primary and an outline or default; quiet buttons carry the long tail of secondary actions in toolbars and table rows.

VariantClassUse it for
Primary.btn--primaryThe one action that moves the task forward. Solid green, never more than one per view.
Outline.btn--outlineThe alternative to the primary in the same decision: Send back next to Approve.
Default.btnEverything else that matters: Export, Save draft, Add line.
Quiet.btn--quietCancel, toolbar actions, row actions. No border until hover.
Accent.btn--accentRare. The same green fill as primary, for empty states and onboarding that sit outside a task.
Danger.btn--dangerDestructive actions in context. Use .btn--danger-solid only inside a confirmation dialog.

Disabled buttons need a reason nearby
If a user can't tell why Approve is greyed out, they'll assume it's broken. Prefer leaving it enabled and explaining on click, or put the reason in a hint right beside it.

Sizes & icons

34px is the default height. 28px is for dense tables and toolbars, 42px for a single call to action on an otherwise empty page. Icons lead the label, never trail it — except a chevron that opens a menu.

Groups & split buttons

Join buttons when they act on the same thing. A split button pairs the common action with its less common siblings — the left half should be safe to press without reading the menu.

Links

Underlined, always. Colour alone fails for one in twelve men, and in a dense table an un-underlined link is just green text.

DoUse a link when the result is a new page. Screen readers announce it as a link and users expect to be able to open it in a new tab.

Keyboard & ARIA

KeyDoes
Enter SpaceActivates the button. Links respond to Enter only — that's the browser default, leave it.
↓ on a split caretOpens the menu and moves focus to the first item.
EscCloses the menu and returns focus to the caret.
  • Use aria-pressed for toggles, not a class. The style is keyed to the attribute.
  • While loading, set aria-busy="true" and keep the button in the tab order. Don't swap the label for "Loading…" — the width jump makes the layout twitch.
  • Icon-only buttons get aria-label. The tooltip is for sighted mouse users; it isn't the accessible name.
